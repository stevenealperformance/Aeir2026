NIRS: bicep = SmO₂ channel 1 (higher values, ~64% → ~19%); quad = SmO₂ channel 2 (lower, ~35% → ~17%). Slopes are linear regression % per second. Long-step slopes skip the first 90 s; short-step slopes use the entire 60 s. O₂Hb (oxygenated) and HHb (deoxygenated) computed each second from SmO₂ × THb, then averaged. Tidal volume / 3.65 interprets 3.65 as vital capacity (L); plotted as TV(L) / 3.65 × 100%. Goal band 75–85% shaded light red.
