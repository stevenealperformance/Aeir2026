Lance vs Both Chay Tests — Step→Recovery Drift

How much does each athlete's step-test value drift from their recovery-test value at the same wattage? Smaller drift = better recovery. Tracking Chay before/after the CO₂ intervention with Lance as an untreated reference point.

How to read this report

Each athlete has a step-test curve and a recovery-test curve. The smaller the vertical gap between them at a given wattage, the better that athlete recovered on that metric.

Three athletes / tests in this report:

  • Lance — single test, no intervention. Pre-baseline reference.
  • Chay T1 — Chay's pre-intervention baseline (April 28).
  • Chay T2 — Chay after 2 weeks of CO₂ suit therapy, no training (May 12).

The third column "Chay change" shows how Chay's drift moved between T1 and T2. Negative = drift shrank (improved), positive = drift grew (worsened).
